# Cloud Shell

**UI:** `/shell` (and related CLI terminal page `/cli`) — browser terminal over WebSocket (`/api/cloudshell`).

Sessions run in the workspace environment. After Homebrew bootstrap, Linuxbrew is on PATH for shell and MCP bash tooling.

Use Cloud Shell for ad-hoc package installs when Softwares does not list a package — or prefer Softwares/Brew when listed.
