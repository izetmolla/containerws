# File Manager

**UI:** `/filemanager` — browse and manage the host filesystem as the panel Linux user.

## Capabilities

- Navigate directories (new tabs open at Home)
- Upload / download / rename / delete
- Zip / unzip (also available via MCP `zip_paths` / `unzip_path`)

Prefer File Manager or MCP filesystem tools over ad-hoc `rm -rf` when possible. Recursive deletes require explicit intent.
