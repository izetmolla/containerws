# Dashboard

**UI:** `/` — host metrics, tools panel, and process list.

## What it shows

- CPU / memory / disk / GPU / network style host stats (via dashboard APIs)
- Live **resource analytics** KPIs — see [Analytics](./analytics.mdx)
- Quick tools and process management (list / kill)

Useful after Softwares installs that add monitoring helpers (`htop`, `nvtop`, etc.).
