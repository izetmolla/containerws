# Settings

**UI:** `/settings` — General, Environments, Options, MCP, Update.

| Page | Purpose |
|------|---------|
| General | Workspace name / description and core prefs |
| Environments | OS environment variables stored in DB |
| Options | Module toggles: Docker, Kubernetes, Proxy Manager, Brew; localhost auto-login; kube options |
| MCP | API keys + standalone listener address/port/enable |
| Update | Self-update / version checks |

## Module defaults

On **new** installs, Docker, Kubernetes, Brew, and Proxy Manager sidebar modules seed **off**. Enable what you need. Existing installs keep prior option values for compatibility.
