# Proxy Manager

**UI:** Overview, Hosts, SSL, Status, Logs.

Host-based reverse proxy management (nginx/traefik style engines depending on configuration). Enable **Proxy Manager** in Settings → Options (defaults off on new installs).

## Typical flow

1. Enable the module
2. Define hosts / routes
3. Attach SSL certificates
4. Apply configuration and watch status/logs

Treat apply/reload as production-impacting on the workspace host.
